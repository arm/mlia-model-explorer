# MLIA Model Explorer Plugin

This site documents the `mlia-model-explorer` post-analysis plugin. The plugin
turns MLIA standardized output and a source model into Model Explorer graph,
overlay, and navigation artifacts, then packages them in a standalone HTML page.

Use the top-level `README.md` for a short introduction. Use these pages when you
need format support, generated artifact behavior, integration details, or the
architecture behind the visualization.

## Contents

- The [Overview](overview.md) introduces the package and its boundaries.
- The [High-level Architecture](high_level_architecture.md) describes the components.
- The [Plugin Integration](plugin_integration.md) page explains MLIA integration.
- The [End-to-end Execution Flow](execution_flow.md) follows artifact generation.
- The [Usage](usage.md) page covers installation and command-line workflows.
- The [Python API](api.md) page documents the supported programmatic interface.
- The [Artifacts](artifacts.md) page explains generated files and behavior.
- The [Model Adapters](adapters.md) page lists format support and limitations.
- The [Development](development.md) page provides contributor guidance.
